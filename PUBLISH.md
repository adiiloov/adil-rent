# Выпуск приложения

## Как теперь устроено обновление

Раньше приложение открывало сайт из интернета, и правки долетали до телефона
сразу после пуша. Теперь файлы лежат **внутри приложения**: оно запускается
мгновенно и работает без сети, но за это приходится платить — **изменения
интерфейса доходят до людей только с новой сборкой в магазине.**

Что обновляется само, без сборки: объявления, брони, фотографии, профили —
всё, что приходит из базы. Что требует сборки: любые правки в `index.html`.

Сайт adilrent.com при этом обновляется как раньше, от каждого пуша.

Вернуть прежнее поведение (если понадобится быстро что-то проверить) — дописать
в `capacitor.config.json`:

```json
"server": { "url": "https://www.adilrent.com" }
```

и выполнить `npx cap sync`. Для подачи в App Store это надо убрать: приложение,
которое просто открывает сайт, отклоняют по правилу 4.2.

## Перед каждой сборкой

```bash
npx cap sync
```

Копирует свежий `www` в оба нативных проекта и подтягивает плагины.
Забыть эту команду — значит собрать приложение со старым кодом.

## Разово: настроить Xcode

`xcode-select` сейчас указывает на Command Line Tools, из-за чего iOS
не соберётся. Выполнить один раз, команда спросит пароль:

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

## iOS

```bash
npx cap open ios
```

В Xcode: выбрать команду разработчика в **Signing & Capabilities**, поднять
**Build → Product → Archive**, дальше **Distribute App → App Store Connect**.

Что нужно приготовить в App Store Connect: описание, ключевые слова,
скриншоты, ссылку на политику конфиденциальности —
`https://adilrent.com` (раздел «Профиль → Конфиденциальность»),
и возрастной рейтинг.

## Android

```bash
npx cap open android
```

В Android Studio: **Build → Generate Signed Bundle** → формат **AAB**.
Ключ подписи создаётся один раз, **его нельзя терять**: без него обновить
приложение в Google Play будет невозможно.

## Когда появятся ссылки на магазины

Вписать их в `index.html`, в начало блока «БАННЕР УСТАНОВКИ»:

```js
var STORE_IOS='https://apps.apple.com/app/...';
var STORE_ANDROID='https://play.google.com/store/apps/details?id=com.adilrent.app';
```

После этого баннер на сайте перестанет предлагать установку веб-версии
и начнёт вести в магазин.

## Что ещё не сделано для магазинов

- **Push-уведомления.** Нужен проект Firebase и его ключи — без них
  уведомления о новых бронях приходить не будут. Пока заявка передаётся
  через WhatsApp.
- **Почта для писем подтверждения.** Встроенный отправитель Supabase
  ограничен несколькими письмами в час; при потоке регистраций люди
  перестанут получать подтверждения. Нужен Brevo или похожий сервис.
